## ⚡ Quick Start (Local Setup)

```bash
# 1. Clone repository
git clone https://github.com/harshithareddy/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build for production
npm run build
```

## 🚀 Free Deployment Guide

### Option 1: Vercel (Fastest ⚡)
1. Push code to your GitHub repo.
2. Go to [vercel.com](https://vercel.com) and import the repository.
3. Click **Deploy** — your site is live immediately!

### Option 2: Netlify
1. Import the repository on [netlify.com](https://netlify.com).
2. Build command: `npm run build`, Publish directory: `dist`.
3. Click **Deploy**.

### Option 3: GitHub Pages
Pre-configured GitHub Actions workflow located in `.github/workflows/deploy.yml`. Go to **Settings > Pages > Source: GitHub Actions**.
